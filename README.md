
# LensMark — 照片检查与局部 MTF 测量

纯浏览器工具：检查成片的曝光分布、平坦区噪声和原像素细节，在合格斜边选区测量成像系统 MTF，并记录同条件照片以辅助比较镜头。

**一张随手拍不能客观分离镜头、机身、对焦、场景和后期的贡献。LensMark 不再生成镜头总分或 S/A/B 等级。**

## 使用流程

1. 导入 JPEG、PNG、WebP 等浏览器支持的图片，或常见相机 RAW。
2. 在“照片检查”中框选关心的区域，查看 100% 原像素、曝光分布和噪声残差。
3. 想比较镜头时，先阅读拍摄指南，再切换“局部 MTF”。选择未截断、两侧平坦、约 5° 的单条斜边；选区至少 48×48、至多 1024×1024 原像素。
4. 中心与四角分别测量并保存；导入另一张照片后，在“测量记录”中检查拍摄参数和来源，导出 CSV。记录保存在当前浏览器，最多 50 条。
5. “导出报告”保存当前分析的 JSON，包括来源、ROI、指标、测量失败原因及限制。

## 测量边界

| 功能 | 当前行为 |
| --- | --- |
| 曝光分布 | 最长边 1280 px 概览采样；可能漏掉细小截断，不评价曝光对错或传感器动态范围 |
| 噪声 | 九个至多 192×192 原像素块中筛选平坦区，去平面 MAD 残差估计；缺少样本返回 null |
| 主体细节 | 框选区域中央至多 512×512 原像素的梯度和 Laplacian 统计，不映射为清晰度分数 |
| MTF | 假定 sRGB 转换曲线；返回局部成像系统响应，非镜头独立光学 MTF |
| 色差、暗角、畸变 | 尚无经过验证的定量实现，显示“无法评价”，给出所需拍摄条件 |
| 对焦、抖动、景深 | 不声称已由单张照片排除 |
| 演示图 | 由演示像素运行同一算法，始终标注合成来源，不加入实拍比较 |
| RAW | 区分 8-bit 渲染图和内嵌 JPEG 预览；二者均不是未处理的线性传感器数据 |

分析在 Web Worker 中进行，需要支持 Worker、OffscreenCanvas 和 createImageBitmap 的现代浏览器。数据不上传；RAW 支持受 LibRaw 构建与相机型号限制。RAW 回退到预览时会明确提示并禁止加入实拍对比。

## 开发与验证

Node.js 24 用于直接运行 TypeScript 回归测试，依赖锁使用仓库中的 bun.lock。

```bash
bun install --frozen-lockfile
npm run dev
npm test
npm run build
```

测试包含已知高斯模糊的解析 MTF50、边缘方向/极性、噪声、无纹理/多边缘/截断拒测、Nyquist 边界、ROI 和比较条件检查。测试通过不等于完成实拍校准或 ISO 认证。
