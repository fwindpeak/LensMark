# LensMark

纯浏览器的照片技术质量与镜头成像评估工具。照片在本地解码和分析，不上传服务器。

## 三步使用

1. **上传照片**：JPEG、PNG、WebP 或常见相机 RAW，可一次选择最多 12 张。自动得到清晰度、曝光保留、纯净度、明暗层次结论与改善建议，无需先框选。
2. **查看镜头**：自动测量九区解析力及中性边缘 RGB 错位；切换“暗角”上传平场，切换“畸变”上传网格。页面提供练习靶下载和可运行的演示。
3. **比较报告**：报告自动保存到当前浏览器，支持补填机身/镜头/曝光参数、同机身不同镜头或同镜头不同光圈比较、各位置 MTF 差值、重复测量中位数与波动、CSV 导出和 JSON 备份/恢复。

照片页可点选主体复查、打开高光/暗部风险叠层、查看 100% 裁剪。局部 MTF 曲线、坐标输入和详细算法说明默认折叠。

## 能测什么

| 功能 | 输出 | 样张条件 |
| --- | --- | --- |
| 照片技术评价 | 参考分、分项结论、问题和建议 | 普通成片；评分不代表审美或镜头排名 |
| 清晰度 | 原像素轮廓 10–90% 过渡宽度 | 有足够稳定的轮廓；天空和虚化不直接判差 |
| 曝光 / 噪声 | 截断比例、直方图、平坦块残差 σ | 噪声需要平坦中间调，缺失不当作纯净 |
| 九区解析力 | 各区 MTF50、同方向采样数、局部曲线 | 中性斜边、同一靶面、无明显截断 |
| 横向色差 | 外侧中性边缘 RGB 重心错位，px | 合适方向的边缘；不把彩色物体当色差 |
| 暗角 | 7×7 相对照度、四角衰减 EV 和不对称量 | 均匀平场，按 sRGB 反变换估计 |
| 畸变 | 网格直线拟合的 k₁、模型角点百分比、残差 | 外侧横竖长直线，单参数径向模型 |

**镜头数值描述当前成片的成像系统响应。** 固定机身、拍摄比例、靶面、光照、对焦与后期之后，才适合据此量化镜头差异。机内校正、锐化和降噪不能自动排除。

参考分是透明的工程启发式，不是经过人类打分数据集标定的美学模型。没有足够轮廓时保留分项结论，不生成总分。场曲、散景、纵向色差、彗差、抗眩光与完整传感器动态范围不由单张随手拍自动量化。

## 开发

需要 Node.js 24 和 Bun。

```sh
bun install --frozen-lockfile
npm run dev
npm test
npm run build
```

技术栈：React 19、TypeScript、Vite、LibRaw WASM、exifr。分析优先在 Worker 中运行；缺少 Worker/OffscreenCanvas 的环境有本地兼容路径。RAW 解码图与内嵌预览明确区分。

记录只存报告和小预览（最多 50 份），不保存原照片或完整 EXIF/GPS。旧版本的局部测量记录会迁移，原有存储不删除。
