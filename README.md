# LensMark - 实拍照片镜头成像质量评估与 MTF 分析器

> 📸 纯浏览器端运行的镜头光学成像质量科学评估与 ISO 12233 斜边 MTF / SFR 分析工具。无需安装任何后端依赖，支持任意实拍照片即传即测。

---

## ✨ 核心特性

1. **🌟 免标板实拍镜头素质评估 (零门槛)**
   - 导入任意实拍照片（风光、人像、静物、街拍、建筑等），**无需手动框选**，一键全图扫描分析。
   - **镜头综合评分 (0~100) 与定级 (S / A / B / C / D)**，客观科学展现镜头光学成像素质。
   - **结构张量相干性去噪 (Structure Tensor Coherence)**：严格过滤随机高频噪点与散粒噪声，杜绝老旧高噪点手机照片产生虚假高锐度。
   - **MAD 稳健噪声估计与信噪比 (SNR dB)**：自动检测并扣除高 ISO 杂讯污染，保障评估客观可信。
   - **JPEG 8x8 块效应与马赛克识别**：自动抑制重度压缩带来的虚假高频网格边缘。
   - **物理分辨率科学标定与封顶**：结合传感器物理像素规模与 LW/PH 真实信息容量约束。
   - **全图空间清晰度热力图 (Heatmap)**：平滑 Turbo/Jet 科学配色，中心锐度 vs 边角软化一目了然。
   - **九宫格像场解析力矩阵**：门控对比中心与 4 边角像场，直观量化**边角画质衰减率 (%)**。
   - **色差与紫边 (CA) 自动量化**：计算高反差边缘 RGB 子像素错位宽度 (px) 与紫边比例。
   - **暗角与相对照度 (Vignetting)**：分析中心与四角曝光照度比值及 EV 损失。
   - **智能光学诊断与实拍建议**：提供通俗易懂的光学评价与光圈收缩建议。

2. **🔬 ISO 12233 专业斜边 MTF / SFR 测量**
   - **自动斜边扫描识别**：全图自动探测所有符合规范的倾斜边缘，点击一键跳转并定位。
   - **物理光强线性化**：严谨遵循 sRGB 逆 Gamma 空间光学解算。
   - **4x 超采样 ESF 与汉宁窗 LSF**：突破传感器 Nyquist 极限。
   - **实时绘制交互式 MTF 频域曲线**：精准求解 MTF50 空间截止频率。

3. **🚀 免上传预设样张体验**
   - 内置 **ISO 12233 测试标板**、**F1.4 大光圈场景**、**F8 广角风光场景** 与 **标准 5.7° 模拟斜边**，即开即测。

bun run build
