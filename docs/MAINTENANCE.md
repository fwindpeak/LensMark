
# 验证与维护

## 已有自动回归

运行 npm test（Node 24）与 npm run build。GitHub Actions 在 PR 和修复分支执行锁定依赖安装、回归测试和生产构建。

12 组测试覆盖：高斯 PSF 对应解析 MTF50 及模糊排序、方向/极性一致性、纯色/随机噪声/多边缘/曲线/轴对齐/截断拒测、Nyquist 内无交点、负 LSF 振铃、sigma=2/8/20 的噪声、纹理拒测与量化下限、ROI 边界与小图、sRGB 转换、来源归因、比较条件和 CSV。

## 合并前仍需验收

- 实际浏览器桌面和窄屏：上传、拖拽/触摸/数字 ROI、100% 查看、模式切换、候选斜边跳转、JSON/CSV 下载。
- 连续上传两个文件、快速切换 ROI、取消和错误后重试，确认照片/元数据/报告始终对应。
- 实拍 JPEG、带旋转 EXIF 图片、无 EXIF、小图、透明 PNG、损坏图片。
- 至少一份可成功完整解码的 Sony ARW 等真实 RAW，以及明确触发 JPEG 预览回退的样本。记录解码尺寸、颜色和 sourceKind。
- 固定机身的真实镜头对照集，检查对焦重复性与测量误差。不能用合成回归代替实拍校准。

浏览器交互验收在本轮因工作环境中断未完成，真实 RAW 样本也未提供；PR 保持草稿。

## 后续扩展原则

新增指标需先定义输入条件、测量方法、无法测量状态、已知干扰和有真值/参考的回归。不要为了填满报告而补默认光学值。下一阶段优先：标准化多张多像场测量、重复测量中位数/离散程度、真正的线性高位深 RAW 管线，再分别实现色差、平场暗角与几何标定。
