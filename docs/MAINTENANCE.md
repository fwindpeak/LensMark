# 验证与维护

## 自动检查

Node.js 24：`npm test`；生产构建：`npm run build`。GitHub Actions 使用锁定依赖，在 PR 与修复分支运行同一检查。

当前 31 项测试覆盖：

- 高斯 PSF 对应解析 MTF50、模糊排序、方向/极性、Nyquist 内无交点、带符号振铃。
- 噪声强度、纹理/截断拒测、量化下限、小图和 sRGB 转换。
- 完整引擎的照片结论、九区独立 MTF、清晰/模糊+噪声排序、纯色不获高分、随机噪声不伪装清晰轮廓。
- RGB 亚像素平移 0 / 0.5 / 1 / 2 px；彩色物体拒测。
- 平场衰减、结构化样张拒测；已知桶形/枕形/零畸变模型；从真实像素检测网格再求畸变。
- 同机身比较、不同光圈比较、位置与方向差异、重复测量中位数及极差。
- JSON 校验、旧记录迁移、CSV 公式安全、取消挂起任务、Worker 旧结果隔离/故障恢复。
- DOM 交互集成：JPEG 解码与混合有效/损坏图片批次、照片结论、曝光叠层、100% 裁剪、镜头/平场/网格流程、靶下载、参数编辑、CSV/JSON、恢复去重、删除撤销、指南、取消后重试、刷新后记录恢复。

DOM 测试使用 JSDOM 与真实 Canvas 像素解码，不是浏览器截图或真机测试。合成回归验证算法实现，不等于实拍标定。

## 发布前建议实机验收

1. 桌面 Chrome / Firefox / Safari 与触屏：真实上传、拖拽、点选与框选、页面滚动、缩放 200%、下载和窄屏表格。
2. 含旋转 EXIF、透明 PNG、HEIC/TIFF 不支持提示、坏图、大图、批量中途取消。
3. Sony ARW 等真实相机 RAW：完整解码和明确触发 JPEG 预览回退，核对尺寸、颜色、处理时间与来源标签。
4. 固定机身、多支镜头、多档光圈的对照集：重复合焦 3–5 次，验证排序、测量波动和失焦干扰。
5. 实拍平场与网格，检查灯光均匀性、打印质量、透视、机内校正对数值的影响。

本轮没有真实相机 RAW/镜头对照样本，也未完成浏览器布局和设备验证。不把这些标成已通过。

## 维护原则

新增结论必须有输入要求、实现方法、失败提示、用户可完成的下一步和正负回归。不能用“未实现”占据核心功能，也不能用默认值填充缺失光学成绩。

照片参考分只做同场景辅助挑片。若要把分数解释为感知质量或镜头排名，必须另建真实标注与对照数据集，不能只调整阈值。
